# EgyGreenera Demo

A Vite + React landing page for EgyGreenera, showcasing export-ready agricultural products, certifications, and market reach.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The app is configured for GitHub Pages deployment using the `gh-pages` package.

```bash
npm run deploy
```
